## ◇ Selected Projects

### 01. Always Plan

`AI Application` `FastAPI` `PostgreSQL` `React`

AI를 활용해 음성 및 문서 입력을 구조화된 일정 정보로 변환하는 애플리케이션.

* AI 기반 정보 추출과 백엔드 데이터 흐름 구현
* 데이터베이스 구조 및 서비스 로직 개선
* 입력부터 결과 활용까지 이어지는 서비스 흐름 개발

### 02. Local Intelligence Hub

`RAG` `FastAPI` `ChromaDB` `React`

사용자가 보유한 문서를 검색하고 근거를 확인할 수 있도록 설계한 로컬 지식 검색 시스템.

* 키워드 검색과 의미 기반 검색을 결합한 하이브리드 검색
* 출처 추적이 가능한 문서 검색 구조 구현
* 신뢰할 수 있는 정보 검색을 위한 시스템 개선

### 03. Harvesting Robot

`Computer Vision` `YOLO` `ROS 2` `RealSense`

작물 인식부터 숙도 판단, 로봇 작업까지 연결하는 수확 로봇 프로젝트.

* 객체 분할 및 포즈 추정 기반 비전 파이프라인 개발
* 깊이 카메라와 로봇 작업 흐름 연계
* 실제 환경에서 동작하는 시스템 관점의 문제 해결
